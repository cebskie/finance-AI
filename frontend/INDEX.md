## 🚀 Getting Started (5 Minutes)

### Step 1: Install
```bash
pnpm install
```

### Step 2: Configure
```bash
cp .env.example .env.local
# Edit .env.local: set NEXT_PUBLIC_API_URL
```

### Step 3: Run
```bash
pnpm dev
```

### Step 4: Test
Open http://localhost:3000 in your browser

### Step 5: Test with Mock API
```bash
# In another terminal
node mock-server.js
```

## 🔌 API Specification

### Endpoints Expected

**Upload Document**
```
POST /documents/upload
→ { documentId, message }
```

**Get Report**
```
GET /documents/{id}/processing-report
→ { document, pages[], summary }
```

## 🆘 Troubleshooting

### Build Errors
```bash
# Clear build cache
rm -rf .next

# Rebuild
pnpm build
```

### API Connection Issues
- Check `NEXT_PUBLIC_API_URL` in `.env.local`
- Verify backend is running
- Check CORS configuration
- Test with mock server: `node mock-server.js`

### Type Errors
```bash
# Run TypeScript check
pnpm tsc --noEmit
```

### Port Already in Use
```bash
# Use different port
pnpm dev -- -p 3001
```
